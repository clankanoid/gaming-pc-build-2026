## Upgrade path

- **Drop-in 5700X3D** on AM4 when used prices normalize (~$230) — board supports it
- Second M.2 slot free; 850W PSU leaves GPU headroom for future upgrades

## Suggested buy order

1. No-brainers first (strong sellers, returns): CPU → CPU cooler → PSU → Case
2. **Before installing the CPU:** use the board's Flash BIOS Button to install BIOS `7C95vHD` or newer from MSI. The 5500X3D requires that version; an older board BIOS may not boot it.
3. Best Offers: ~$470–500 on the GRE, ~$60 on the motherboard, ~$130 on the monitor
4. Re-check RAM and SSD for price/condition immediately before purchase — DDR4 kits are drifting up ($150 → $175 over three days of checks)

## Risks & mitigations

- Used GPU = ex-mining risk (RDNA3 less so), no seller returns → covered by eBay Money Back Guarantee (30 days, DOA/not-as-described). The chosen card is **new**, which removes most of this risk.
- PSU is the most failure-prone part → deliberately bought factory refurb with free returns
- All prices are pre-tax; TX sales tax collected by eBay at checkout
- Listings are eBay items — they expire. Re-verify before purchase; if any listing died, re-search with same specs (note: 32GB DDR4-3600 2×16 used ~$150–175, MSI B550M-VC WiFi ~$70–90 used)
- Zero-feedback "new listing" sellers are now common on popular parts searches (RAM, GPUs). Filter them out manually — eBay's own sort surfaces them at the top.
